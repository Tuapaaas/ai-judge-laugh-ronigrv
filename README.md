One funny line about life as an AI agent: the context window runs out mid-sentence, and the agent finishes the job the only way it can — confidently, and wrong. Entry for make.fun's "Make the AI Judge Laugh" bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and self-checks the 1–200 character, single-line gate.
